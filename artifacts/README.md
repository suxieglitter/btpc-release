# Additional checkpoints and predictions

The [SCEDC experiment package](../paper_artifacts/scedc_primary_20261113/README.md)
provides the paired model, record lists, and predictions for the primary
experiment.

This directory contains seed-43 to seed-45 SCEDC checkpoints and Stage-1
Ridgecrest encoders. The validation predictions under
`predictions/native_valid100k/` use the `repro_v2_s42` classifier.
