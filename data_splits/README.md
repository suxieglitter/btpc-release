# Auxiliary record lists

`native_valid_100k.csv` lists the fixed auxiliary validation records used for
the seed comparison, ablation, and picking-offset analyses.
`tsne_subsample_10k.csv` lists the records for the t-SNE visualization.

The [SCEDC experiment package](../paper_artifacts/scedc_primary_20261113/README.md)
provides the record lists paired with the primary experiment predictions.
