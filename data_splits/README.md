# Data splits

Row-level split lists for every batch used in the paper, all generated with
fixed seeds. Everything except `tsne_subsample_10k.csv` (a seeded subsample
of `native_valid_100k.csv`) is regenerated by `scripts/make_event_splits.py`
(idempotent). Descriptive statistics are in `split_summary.csv`; seeds, pool
sizes and exclusion bookkeeping are in `manifest.json`.

## Source data

- Native file: `scsn_p_2000_2017_6sec_0.5r_fm_train.hdf5` (2,494,194
  records; X/Y/snr + evids/sncls/mag/dist; eligible pool of Up/Down records
  with SNR in [0, 1000): 1,656,723). Distributed by the Southern California
  Earthquake Data Center (Ross et al., 2018):
  https://service.scedc.caltech.edu/ftp/Ross_FinalTrainedModels/scsn_p_2000_2017_6sec_0.5r_fm_train.hdf5
  (also available via SeisBench as `Ross2018JGRFM`)
- Consensus file: `scsn_consensus_fm_CFM_EQ.hdf5` (1,246,902 records) — a
  derived dataset (records on which the manual label and the CFM and EQPolar
  predictions agree); not redistributed, see the main README

## Batches

| File | n | Role | Generation |
|---|---|---|---|
| `native_train_10k.csv` | 10,000 | Training batch; also the primary prediction target (dataset-adaptive usage) | Seeded selection (2x candidate draw + binary-polarity filter + first n), selection seed 42 |
| `reference_200.csv` | 200 | Reference records used at prediction time to map clusters A/B onto Up/Down; no training role | 100 per class drawn from an SNR >= 50 bank (build seed 42, pool 5000 per class; sample seed 20260404) |
| `native_valid_100k.csv` | 100,000 | Held-out validation batch | Random draw from the remaining Up/Down records, training-batch and reference rows excluded, seed 20260914 |
| `consensus_100k.csv` | 100,000 | Secondary consistency-check batch | Random draw from the consensus file, records matching the training batch or references excluded by (evid, sncl), seed 20260914 |
| `tsne_subsample_10k.csv` | 10,000 | Subsample for the t-SNE feature-space panels | Seeded subsample of `native_valid_100k.csv` (`np.random.default_rng(20260914)`) |

CSV columns: `source_index, evid, sncl, label, label_name, snr, mag, dist`
